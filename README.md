# OIA Group website

Next.js static website foundation for `oia.group`, designed for Cloudflare Pages.

## Local development

```bash
npm install
npm run dev
```

## Cloudflare Pages

- Framework preset: **Next.js (Static HTML Export)**
- Build command: `npm run build`
- Build output directory: `out`
- Pin a current Node.js release with the `NODE_VERSION` environment variable.

The initial build uses tonal image placeholders because the source Figma Sites file did not expose downloadable assets to the connected account. Replace these with approved project photography under `public/images`.
